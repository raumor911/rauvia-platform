# Rendimiento (Baseline)

- **Herramientas:** Vite realiza code-splitting, minificación y optimización de CSS/JS.
- **Imágenes:** Se usarán formatos modernos (WebP/AVIF) cuando sea posible, mediante etiquetas `<picture>` o `loading="lazy"`.
- **SVG:** Se mantienen los assets vectoriales (no convertir a PNG), optimizando el código interno si es necesario.
