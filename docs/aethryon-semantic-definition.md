# Definición Semántica de AETHRYON

- **Clasificación:** Sistema de análisis y convergencia (Metodología / Framework).
- **Relación:** Desarrollado y operado por RAUVIA.
- **Propósito:** Interpretar señales, identificar fricción y estructurar decisiones ejecutables.
- **Lo que NO es:** Un software SaaS de acceso público, un producto de licencia de software (a menos que se ofrezca como tal, actualmente es una herramienta/metodología interna usada por RAUVIA en la entrega de sus servicios).
