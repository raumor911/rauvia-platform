Prioridad: identidad/perfiles → evidencia de casos → atribuciones acreditadas → referencias pertinentes. No fabricar backlinks, testimonios, certificaciones, resultados clínicos ni investigación. Un perfil propio no cuenta como corroboración independiente.

Cada revisión futura conserva URL, fecha, texto, entidad, relación, fuente, permisos y límites. Sólo entonces clasificar PARTIAL_EXTERNAL o SUPPORTED_EXTERNAL; STRONG_INTERNAL / WEAK_EXTERNAL requiere evidencia de ambas partes. No confundir ausencia de revisión con ausencia de referencias.
