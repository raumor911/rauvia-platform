# Política de Fuentes

- Cada artículo con datos externos debe citar la fuente.
- Formato: URL hipervinculada, Autor/Organización, Fecha.
- Prioridad: Fuentes primarias, papers, documentación oficial (ej. manuales técnicos).

## Aplicación V74

La capa estática aplica esta política mediante [knowledge-evidence-model.md](knowledge-evidence-model.md), [knowledge-publication-policy.md](knowledge-publication-policy.md) y [knowledge-maintenance.md](knowledge-maintenance.md). No sustituye esta autoridad ni convierte cobertura editorial en observación de mercado.
