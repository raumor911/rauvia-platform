# Auditoría Semántica Inicial (Fase 2)

## Entidad Principal
RAUVIA aparece descrita de varias maneras, pero su nombre canónico debe ser estable como "RAUVIA CONSULTORIA Y DESARROLLO TECNOLOGICO".

## Conceptos Propios
- **AETHRYON:** Definido como sistema de análisis y convergencia.
- **Sistemas comerciales, Arquitectura Operativa, Desarrollo Tecnológico:** Necesitan vocabulario controlado para evitar solapamientos.

## Conclusión
Se requiere centralización de entidades, JSON-LD estructurado y unificación de términos a lo largo del sitio para asegurar la identidad semántica clara frente a LLMs y bots de búsqueda.
