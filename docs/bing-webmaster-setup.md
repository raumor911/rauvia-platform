# Configuración en Bing Webmaster Tools

- **Verificación:** Importar propiedad desde Google Search Console.
- **Copilot / IA:** Bing usa su índice para alimentar a Copilot. Es vital monitorizar "Search Performance" > "Bing Chat / Copilot" si los datos de IA se exponen separadamente en su interfaz.
- **Sitemap:** Mismo que GSC.
