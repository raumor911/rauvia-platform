# Configuración en Google Search Console

- **Propiedad:** Dominio (`rauvia.com.mx`).
- **Verificación:** Vía DNS (TXT record) preferentemente.
- **Sitemap:** Enviar `https://rauvia.com.mx/sitemap.xml`.
- **Inspección de URLs:** Verificar que Googlebot procesa correctamente las páginas prerenderizadas (Client-Side HTML vs Rendered HTML).
