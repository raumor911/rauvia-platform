# Datos Estructurados Básicos (Schema)

Se ha implementado (o se debe validar) el componente `JsonLd.tsx` que inyecta los siguientes grafos mínimos:
- `Organization`: RAUVIA CONSULTORIA Y DESARROLLO TECNOLOGICO.
- `WebSite`: URL principal y name.
- En `/blog/`, WordPress generará esquemas `BlogPosting` a través de su plugin SEO (ej. Yoast o RankMath).

No se exponen direcciones físicas detalladas si no están en la UI pública.
